# Changelog

## 0.1.1
- Saves from season boxes (like SWOFTY Seasons 2017) now show up. Before, only Create New was offered.
- Fixed a crash when deleting a save with F2.
- Deleting your last save now updates the screen straight away.

## 0.1.0
- First release.
- Up to 10 Grand Prix saves, one card each on the Grand Prix screen, with a Create New card under them.
- Create New starts a new Grand Prix in its own save, with no overwrite warning.
- F2 deletes the selected save; leaving a new Grand Prix before it starts keeps your saves.
